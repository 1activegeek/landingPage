## Phase 4: Styling (Steps 11–15)

### Step 11 — Apply Catppuccin colors to `assets/css/style.css`

**Dark mode (Catppuccin Mocha) — PRIMARY:**
```css
[data-theme="dark"] {
  --bg: #181825;       /* Mantle */
  --bg2: #1e1e2e;      /* Base */
  --text: #cdd6f4;     /* Text */
  --title: #ffffff;    /* White */
  --brand: #45475a;    /* Surface 1 */
  --border: #313244;   /* Surface 0 */
}
```

**Light mode (Catppuccin Latte):**
```css
:root {
  --bg: #eff1f5;       /* Latte Base */
  --bg2: #e6e9ef;      /* Latte Mantle */
  --text: #4c4f69;     /* Latte Text */
  --title: #1e1e2e;    /* Dark */
  --brand: #9ca0b0;    /* Latte Surface 1 */
  --border: #ccd0da;   /* Latte Surface 0 */
}
```

### Step 12 — Set dark mode as default
- **`_layouts/Post.html`**: Add `data-theme="dark"` to `<html>` tag
- **Toggle JS**: Change fallback from `'light'` to `'dark'`

### Step 13 — Add card grid & landing page CSS
- `.landing-name` — body font size, bold, `var(--title)`
- `.landing-more` — 0.85em, subtle underline, reduced opacity
- `.card-grid` — CSS Grid 2x2, collapses to 1 column on mobile
- `.card` — `var(--bg2)` background, border, no text-decoration, hover effect
- `.card-title` / `.card-desc` — weight and size differentiation

### Step 14 — Restyle links site-wide
- `a { color: var(--text); text-decoration: underline; text-decoration-thickness: 1px; text-underline-offset: 2px; }`
- `a:hover` — no color change, keep underline
- Remove teal/brand color from links
- Ensure `.card` and nav links have `text-decoration: none` overrides

### Step 15 — Clean up orphaned CSS
- Remove `.hamburger`, `.dropdown`, `.dropdown-menu` CSS rules
- Simplify `.nav` CSS to flexbox row with space-between
